📍 Contexto

Ciudad Madero y su Sistema Hídrico

🗺️
Ubicación estratégica
Ciudad Madero es un municipio costero de Tamaulipas, México, abastecido por el Sistema Lagunario-Chairel y plantas potabilizadoras de COMAPA Sur.
🏞️
Laguna del Chairel
Principal fuente de agua superficial de la región. Enfrenta la proliferación de lirio acuático (Eichhornia crassipes) que obstruye el flujo y eleva costos de potabilización.
🏭
Organismos operadores
COMAPA Sur — Red de distribución de agua potable

CAEAT — Comisión del Agua del Estado de Tamaulipas
⚠️ Problemática

Tres Crisis Hídricas Urgentes

💧 Crisis 1
40–60%
del agua potable perdida por fugas no detectadas en Latinoamérica
Las fugas en tuberías subterráneas permanecen sin reportarse durante días o semanas por falta de un canal de reporte ciudadano eficiente.
🌿 Crisis 2
+30%
de superficie lagunar cubierta por lirio en temporadas de lluvia
El lirio acuático consume el oxígeno del agua, mata ecosistemas y encarece la potabilización en las plantas de tratamiento regionales.
🔬 Crisis 3
Variable
calidad del agua por intrusión salina y sedimentos
Sin herramientas accesibles, el ciudadano no puede detectar variaciones de turbidez o contaminación temprana en el agua que consume.
💡 Solución

¿Qué hace Madero H2O?

Una aplicación web que convierte la cámara del ciudadano en un sensor de monitoreo hídrico impulsado por IA.

Concepto central: El usuario toma una fotografía del problema → la IA lo analiza en segundos → se genera un reporte geolocalizado → las autoridades actúan más rápido.
📱
Para el ciudadano
Interfaz simple: elige el tipo de problema, sube una foto y obtiene un análisis instantáneo.
🏛️
Para COMAPA Sur
Dashboard con mapa de calor de todos los reportes priorizados por severidad y geolocalización.
🌊
Para las brigadas
Alertas de zonas con mayor concentración de lirio para optimizar operativos de limpieza.

Asistente de Calidad y Turbidez

¿Cómo funciona?
1️⃣ Usuario toma foto de un vaso de agua sobre fondo blanco
2️⃣ Gemini analiza los píxeles: color, turbidez, partículas visibles
3️⃣ Compara con la norma NOM-127-SSA1-2021 de forma orientativa

🤖 Inteligencia Artificial

El Agente: Google Gemini 2.5 Flash

👁️
Visión Multimodal
Gemini puede analizar imágenes y texto simultáneamente. Recibe la foto + el prompt especializado y devuelve un JSON estructurado con el diagnóstico.
🎯
Prompts Especializados
Cada módulo tiene un prompt diseñado por expertos en infraestructura hidráulica, ecología acuática y análisis colorimétrico con contexto local de Tamaulipas.
⚡
Respuesta en <5s
Gemini Flash está optimizado para latencia baja. El usuario recibe el análisis completo y la recomendación en menos de 5 segundos desde que sube la foto.
¿Por qué Gemini en lugar de YOLO? — Gemini realiza en un solo API call lo que requeriría: detección de objetos (YOLO) + clasificación + análisis de color + generación de texto. Sin instalaciones locales de PyTorch ni GPU.
🏗️ Arquitectura

Stack Técnico

🐍
Backend: Python + Flask
Agente orquestador con 5 endpoints REST. Enruta cada imagen al prompt correcto.
🤖
IA: Gemini 2.5 Flash
Análisis multimodal de imagen + prompt → JSON estructurado de respuesta.
🗄️
DB: SQLite + SQLAlchemy
Historial persistente de reportes. En Vercel usa /tmp.
🗺️
Mapa: Leaflet.js
Mapa de calor open source centrado en Ciudad Madero con markers por módulo y severidad.
🎨
Frontend: HTML + CSS + JS
SPA glassmorphism dark mode. Drag-and-drop, geolocalización nativa y animaciones de agua.
☁️
Deploy: Vercel + GitHub
CI/CD automático. Cada push a main redespliega la app en segundos.
